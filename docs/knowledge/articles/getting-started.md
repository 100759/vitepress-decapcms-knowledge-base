# 快速开始

这是一篇示例知识条目。以后你可以在 Decap CMS 后台创建新的条目，它们会作为 Markdown 文件保存到 `docs/knowledge/articles` 目录。

## 建议流程

1. 在 GitHub 建好仓库并推送代码。
2. 在 Cloudflare Pages 连接仓库。
3. 配置 Decap CMS 的 GitHub OAuth 登录。
4. 访问 `/admin/` 写作并发布。

## 图片上传

CMS 上传的图片会保存到 `docs/public/images/uploads`，发布后的访问路径是 `/images/uploads/...`。
